Comment on l'installe ?

Trois étapes, une quinzaine de minutes.

1
Crée ton bot sur le Developer Portal Discord et récupère le token + client ID/secret.
2
Lance le one-liner sur ton serveur ou Raspberry Pi. Le script te guide pour la config.
3
Invite le bot sur ton serveur Discord. Le dashboard est accessible sur le port choisi.

D'où vient le nom ?

Dans les années 60, les astronomes ont découvert des objets d'apparence minuscule mais à la puissance incompréhensible — ils les ont appelés quasars. Quasar est un bot Discord construit sur la même idée : petit, auto-hébergeable en une ligne sur n'importe quelle machine avec Docker installé, mais capable de ce que d'autres cachent derrière un paywall. Open source, gratuit, sans limites artificielles.
